# Atividade 7 - Soma de Números

## Descrição

Fazer um programa em Java para ler vários números inteiros e realizar a soma desses números.

O programa continua solicitando números enquanto o valor digitado for diferente de 0.

Quando o usuário digitar 0, o programa encerra a leitura e mostra na tela a soma de todos os números informados.

## Funcionamento

O programa utiliza:

- Scanner para receber os números;
- Uma variável soma para armazenar o resultado;
- A estrutura de repetição while;
- O número 0 para finalizar o programa.

## Exemplo

### Entrada

10
20
5
0

### Saída

35

## Tecnologias utilizadas

- Java
- Scanner
- Estrutura de repetição while

## Objetivo

Praticar entrada de dados, variáveis, operações matemáticas e estruturas de repetição em Java.
