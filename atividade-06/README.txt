Exercício: Dia da Semana em Java
Este projeto consiste em uma aplicação de console simples desenvolvida em Java para praticar o uso de estruturas condicionais (switch-case) e leitura de dados pelo teclado.

📌 Descrição
O programa lê um número inteiro de 1 a 7 fornecido pelo usuário via terminal e exibe o nome do dia da semana correspondente. Caso o número informado esteja fora dessa faixa, é exibida uma mensagem de valor inválido.

Mapeamento dos Dias:
1 ➔ Domingo

2 ➔ Segunda-feira

3 ➔ Terça-feira

4 ➔ Quarta-feira

5 ➔ Quinta-feira

6 ➔ Sexta-feira

7 ➔ Sábado

🛠️ Tecnologias Utilizadas
Linguagem: Java (JDK 8 ou superior)

Classe para Entrada: java.util.Scanner
