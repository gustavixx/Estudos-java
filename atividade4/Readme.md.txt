# Atividade 4 - Condicional de Horário

## Descrição

Nesta atividade foi desenvolvido um programa em Java que solicita ao usuário uma quantidade de horas e apresenta uma mensagem de acordo com o horário informado.

## Objetivo

Praticar estruturas condicionais em Java utilizando `if`, `else if` e `else`.

## Funcionamento

O programa funciona da seguinte maneira:

- Horário menor que 12: exibe "bom dia".
- Horário menor que 18: exibe "boa tarde".
- Horário igual ou maior que 18: exibe "boa noite".
