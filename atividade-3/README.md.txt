# 🔄 Atividade - Casting em Java

## 📚 Descrição

Esta atividade foi desenvolvida para praticar o conceito de **Casting em Java**, utilizado para converter um tipo de dado em outro.

## 🎯 Objetivo

Compreender como realizar conversões entre diferentes tipos de dados em Java, utilizando **Casting implícito** e **Casting explícito**.

## 💻 Conceitos praticados

- Casting implícito
- Casting explícito
- Conversão de tipos numéricos
- `int`
- `double`
- `float`
- `byte`
- `short`
- Operações matemáticas com diferentes tipos

## 🧠 O que é Casting?

Casting é a conversão de uma variável de um tipo de dado para outro.

### Casting implícito

Acontece quando o Java realiza a conversão automaticamente, geralmente de um tipo menor para um tipo maior.

Exemplo:

int numero = 10;
double resultado = numero;ss
